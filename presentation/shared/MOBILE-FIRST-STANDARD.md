# Wedding Chapter Mobile First Standard

所有 Experience 的手機畫面皆以 9:16 作為獨立構圖基準，不得由桌機版等比例縮小。

- 每個場景需重新安排 Hero、主視覺、標題、留白、操作與卡片。
- 標題須依 320–430px 寬度設計自然斷行，不使用縮放解決溢出。
- 主視覺需重新裁切與定位；不可直接縮小桌機素材群組。
- 文字以高對比深色或符合背景對比的品牌色呈現，內文字級不得低於 14px。
- 選項採單欄、橫向滑動或手機專用牌組；不可直接壓縮桌機多欄網格。
- 主要操作高度至少 48px，保留 safe-area 與拇指操作空間。
- 390px 設計實驗室預覽必須具有與實際手機 media query 相同的構圖規則。
- 320、375、390、430px 均不得產生非預期橫向捲動或文字重疊。
